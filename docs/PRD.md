## 1. 목표

조사단이 동해의 길을 구간마다 직접 걷고 재서 **동해시 무장애지도**를 만든다. 휠체어·유모차 사용자가 "이 길로 갈 수 있는가"를 지도에서 판단할 수 있게 하는 것이 목적이다.

무장애지도에 필요한 것은 "어디에 장애물이 있다"만이 아니라 **"이 길은 지나갈 수 있다"**는 정보다. 장애물 제보만으로는 문제없는 길을 알 수 없다. 그래서 이 서비스의 기본 단위는 **구간 조사**다. 조사원이 길 구간을 걸으며 장애물과 경사를 기록하고, 구간마다 통행 가능 여부를 확정한다.

**본선 목표 (2026-11-20\~21):** 동해 청소년센터와 동해시종합버스터미널 주변에서 아래 흐름을 실제 폰으로 끊김 없이 시연한다.

> 조사원 구간 조사(장애물·경사 실측) → 구간 통행 등급 지도 → **조사한 길로 무장애 길 안내** → 시민 제보가 점검 목록에 반영 → GeoJSON·CSV 개방

길 안내는 모은 데이터가 실제로 쓸모 있다는 걸 보여주는 데모다. 조사를 마친 구간 안에서만 동작한다.

### 확정된 결정

| 항목 | 결정 |
| --- | --- |
| 운영 모델 | **조사단 중심.** 팀·자원봉사자 조사원이 구간을 조사하고 실측한다. 시민 제보는 "여기 봐주세요"라는 점검 요청 신호다. 공무원 참여는 발표에서 제안한다(동해시 미접촉) |
| 음성 제보 | 제외 |

| 길 안내 | **조사 구간 한정 데모.** 조사를 마친 구간만으로 경로를 찾고, 일반 최단 경로와 비교해 보여준다([R-301](#길-안내-데모)) |

| 플랫폼 | 모바일 웹(PWA). 아이폰·안드로이드 모두 설치 없이 동작 |
| 시연·테스트 지역 | 동해 청소년센터 주변, 동해시종합버스터미널 주변 |
| 개발 체제 | 개발 1명(MVP), 나머지 팀원은 디자인과 실기기·현장 테스트(조사원 역할 겸함) |

## 2. 하지 않는 것

- 동해 전역 길 안내, 조사하지 않은 구간을 지나는 경로 안내. 데이터가 없는 곳에서 경로를 단정하면 휠체어 사용자를 계단이나 턱 앞으로 보낼 수 있다
- 음성 길 안내, 실시간 위치 따라가기(내비게이션)
- OSM에 데이터 올리기
- 회원가입 화면, 조사원 자가 등록
- 음성 제보(STT)
- 사진 속 얼굴·번호판 자동 가림. 대신 사진은 공개하지 않는다
- 오프라인 조사(통신 없는 곳에서 저장 후 나중에 전송)
- 조사원 일정·구역 배정 관리
- 네이티브 앱, 다국어 지원(한국어만), 시청 업무 시스템 연동

## 4. 사용자 스토리

**조사원**
- **US-1** 조사원으로서, 조사 지역에서 아직 조사하지 않은 구간과 시민 제보 위치를 한 지도에서 보고 어디로 갈지 정하고 싶다.
- **US-2** 구간을 걸으며 발견한 장애물을 바로 등록하고, 턱 높이와 폭을 입력하고 싶다.
- **US-3** 폰을 바닥에 놓아 구간의 경사를 재고 싶다.
- **US-4** 구간을 다 걸으면 "통행 가능 / 주의 / 통행 어려움"으로 조사를 마치고 싶다.
- **US-5** 시민 제보 현장에 가서 실제로 장애물이 있는지 확인하고 처리하고 싶다.
- **US-6** 장난 제보를 숨기고 싶다.

**지도 이용자**
- **US-7** 휠체어 사용자로서, 이동 전에 어느 길이 지나갈 수 있는지 색으로 보고 싶다.
- **US-8** 그 정보가 실제로 잰 것인지 추정인지, 언제 조사한 것인지 알고 싶다.
- **US-8a** 버스터미널에 내린 휠체어 사용자로서, 목적지를 찍으면 계단과 높은 턱을 피해 갈 수 있는 길을 안내받고 싶다.

**시민 제보자**
- **US-9** 지나가다 높은 턱을 보면, 앱 설치 없이 QR로 들어가 버튼 몇 번으로 위치를 알리고 싶다.
- **US-10** 상황이 애매하면 사진과 짧은 글로 설명하고 싶다.

**데이터 사용자**
- **US-11** 전체 데이터를 GeoJSON·CSV로 받아 QGIS에서 바로 열고 싶다.
- **US-12** 지도 범위와 조건으로 API를 조회하고 싶다.

## 6. 기준값

현장에서 직접 재며 보정한다. 아래는 출발점이다.

### 구간 통행 등급 (자동 제안 기준)

| 등급 | 조건 (초기값) |
| --- | --- |
| 통행 가능 | 진행 방향 경사 ≤ 5.6%(1/18), 턱 ≤ 2cm, 막는 장애물 없음 |
| 주의 | 진행 방향 경사 5.6\~8.3%(1/12), 또는 턱 2\~?cm, 또는 좁은 길·파손 |
| 통행 어려움 | 진행 방향 경사 > 8.3%, 또는 계단, 또는 넘을 수 없는 턱 |

경사·턱 기준은 장애인등편의법 시행규칙의 접근로 기준에서 가져왔다(조항 확인 필요). 횡경사 기준과 '주의' 턱 높이 상한은 현장 실측(T4)으로 정한다.

## 7. 비기능 요구사항

- **플랫폼:** 모바일 웹(PWA), HTTPS 필수. 아이폰 Safari와 안드로이드 Chrome 최신 버전. 안드로이드 1대 이상으로 반드시 테스트
- **현장 사용성 (조사 화면):** 한 손 조작, 야외에서 읽히는 고대비, 측정 중 화면 꺼짐 방지
- **접근성 (지도·제보 화면):** 터치 영역 44pt 이상, 색만으로 정보를 구분하지 않음, 스크린리더 라벨, 시스템 글자 크기를 키워도 레이아웃 유지
- **성능:** 조사 기록·제보 저장 응답 2초 이내(LTE 기준)
- **개인정보:** 공개 데이터에 제보자 정보·원문·사진 없음. 업로드 사진 EXIF 제거
- **가용성:** 본선 기간과 이후 30일 동안 서비스 유지. UptimeRobot 알림

## 9. 시연 지역과 사전 데이터

| 지역 | 용도 |
| --- | --- |
| 동해 청소년센터 주변 | 본선 시연. 조사원 시연, 심사위원 QR 제보 |
| 동해시종합버스터미널 주변 | 본선 전 현장 조사(T4), 기준값 보정, 시연용 조사 완료 구간 확보 |

각 지역 범위(반경 약 1km 안팎)는 지도에서 확정한다. 본선 전 준비할 것은 다음과 같다.

- 두 지역 OSM 보행 가능 길을 구간으로 나눠 DB 적재
- 두 지역 DEM 추정 경사 계산
- 터미널 주변 실제 조사 데이터 (지도가 비어 보이지 않게)

### 길 안내를 위한 조사 방식

길 안내는 조사한 구간이 **끊기지 않고 이어져 있어야** 동작한다. 여기저기 흩어진 구간을 조사하면 지도는 채워져도 경로는 나오지 않는다. 그래서 조사는 이렇게 한다.

1. 시연할 출발·도착 지점을 먼저 정한다. 터미널과 청소년센터가 걸어갈 만한 거리라면 **터미널 → 청소년센터**가 가장 좋다. "버스로 동해에 온 휠체어 사용자가 해커톤 장소까지 가는 길"이라는 실제 장면이 된다
2. 두 지점 사이에서 일반 최단 경로와 그 주변 대안 길을 묶어 조사 범위로 잡는다
3. 그 범위 안의 구간을 빠짐없이 조사한다. 일반 경로에 계단·턱 같은 장애물이 있는 곳을 찾으면 비교 시연의 핵심 장면이 된다
4. 시간이 남으면 각 지점 주변으로 넓힌다

## 10. 본선 시연 시나리오

본선 1일차에 현장을 조사하고, 2일차에 그 데이터로 시연한다. 발표의 중심 문장은 "어제 우리가 직접 걷고 잰 길로 안내합니다"이다.

1. 지도에서 조사 지역을 보여준다. 조사한 구간은 등급 색, 조사하지 않은 구간은 DEM 추정 점선 (R-401\~403)
2. **터미널 → 청소년센터 길 안내:** 일반 최단 경로는 계단·턱을 지나고, 무장애 경로는 그걸 피해 조금 돌아간다는 걸 나란히 보여준다 (R-301\~302)
3. 조사원이 청소년센터 앞 구간을 걸으며 턱을 등록하고 경사를 잰다 (R-103\~105)
4. 조사를 마치면 구간 색이 바뀌고, 그 구간이 길 안내에 바로 쓰인다 (R-106, R-301)
5. 심사위원이 QR로 빠른 제보 → 조사원 점검 목록에 뜬다 → 확인 처리 (R-201\~203, R-107\~108)
6. 다운로드한 파일을 QGIS에서 열어 보여준다 (R-502)

## 12. 디자인 팀이 정할 것

- 조사 화면 흐름: 구간 선택 → 장애물 등록·측정 → 조사 완료까지 몇 단계로 할지
- 경사 측정 안내 화면: 폰을 놓는 법, 180도 돌리는 법
- 통행 등급 색과 선 모양 (색약에서도 구분, 실측과 추정 구분)
- 장애물 아이콘 5종
- 길 안내 화면: 출발·도착 입력 방식, 무장애 경로와 일반 경로 비교 표현, 경로가 없을 때 안내
- 시민 빠른 제보 화면 (유형 버튼 먼저 vs 위치 확인 먼저)
- QR 포스터 (터미널·청소년센터 게시용)
